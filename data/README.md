# data/

`CatalogoServicios.xlsx` es el archivo original entregado por el catedrático y se conserva
sin modificaciones. Es de solo lectura para el asistente (`hooks/guard.sh`) y su SHA-256
está fijado en `docs/contexto/excel-sha256.txt` desde antes de empezar:

```bash
shasum -a 256 -c docs/contexto/excel-sha256.txt
```
