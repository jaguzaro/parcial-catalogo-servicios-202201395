sin cambios. Es de solo lectura para el asistente, por `hooks/guard.sh`, y su SHA-256 quedo
fijado en `docs/contexto/excel-sha256.txt` desde antes de empezar:

```bash
shasum -a 256 -c docs/contexto/excel-sha256.txt
```
