| D14 | 2026-10-04 | Backend en Go con la libreria estandar `net/http` y los patrones de ruta de Go 1.22, `pgx/v5` para PostgreSQL, `goose` con migraciones embebidas y `excelize` para leer el Excel. | Un framework web completo, o Node con Express, o Python con FastAPI. | El binario de Go se compila en una imagen sin dependencias de ejecucion, que es lo que hace facil el arranque desde un clon limpio. | D15 | 2026-10-04 | Contrasenas con argon2id y sal aleatoria por usuario. | bcrypt, o PBKDF2. | El enunciado pide un algoritmo especializado con sal. argon2id es el recomendado hoy y resiste mejor el crackeo con hardware dedicado. bcrypt tambien habria servido, pero limita la contrasena a 72 bytes. | IA. |
| D16 | 2026-10-04 | Sesion con token opaco aleatorio en cookie `HttpOnly` y `SameSite=Lax`. En la base se guarda solo su SHA-256, con fecha de expiracion. Guardar solo el hash significa que leer la tabla de sesiones no permite suplantar a nadie. | IA. |
| D17 | 2026-10-04 | Interfaz en React con Vite y TypeScript, con `react-router` y sin libreria de componentes pesada.
