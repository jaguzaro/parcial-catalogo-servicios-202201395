# Evidencias

- `harness/` — bloqueos de hooks, ciclos tarea → cambio → control → fallo → corrección → éxito.
- `sesiones/` — salida JSON y metadatos (fecha, modelo, versión, commit base, código de salida)
  de cada ejecución headless de Claude Code.
- `pruebas/` — salidas de `make check` / pruebas con fecha y commit.

Regla: aquí solo hay salidas reales de comandos. Nada se redacta a mano como si fuera resultado.
