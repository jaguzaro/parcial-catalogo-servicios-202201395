# Evidencias

- `harness/`: bloqueos de los hooks y ciclos completos de tarea, control, fallo,
  correccion y nueva comprobacion.
- `sesiones/`: salida JSON y metadatos de cada ejecucion headless de Claude Code, con
  fecha, modelo, version de la herramienta, commit base y codigo de salida.
- `pruebas/`: salidas de `make check` y de las pruebas, con fecha y commit.

Aqui solo hay salidas reales de comandos. Nada se escribe a mano como si fuera resultado.
